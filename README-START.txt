HOW TO OPEN THE APPLICATION:
----------------------------

Option 1: Double-click "START-HERE.bat"
Option 2: Double-click "OPEN-APP.vbs"
Option 3: Double-click "index.html" directly

If none work, follow these steps:
----------------------------

METHOD 1: Use Browser Directly
1. Open Chrome, Firefox, or Edge browser
2. Press Ctrl + O (Open File)
3. Navigate to this folder
4. Select "index.html"
5. Click Open

METHOD 2: Right-click Method
1. Right-click on "index.html"
2. Select "Open with"
3. Choose your browser (Chrome/Firefox/Edge)
4. Check "Always use this app"
5. Click OK

METHOD 3: Drag and Drop
1. Open your browser
2. Drag "index.html" into the browser window

TROUBLESHOOTING:
----------------------------
If you see "File not found" or blank page:
- Make sure ALL files are in the same folder
- Check that app.js and style.css exist
- Try a different browser (Chrome recommended)
- Disable browser extensions
